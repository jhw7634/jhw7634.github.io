# JS 오답킬러

자바스크립트 기초 공부용 퀴즈 웹앱 (홈 화면에 설치 가능, 오프라인 지원). SQLD 오답킬러와 같은 구조이고 탭은 이론 / 연습 / 함정 / 분석입니다.

- `index.html` 앱, `questions.js` 데이터(이론 설명, 함정 요약, 연습·함정 문제), `manifest.webmanifest`·`sw.js`·`icon-*.png` 설치용, `privacy.html` 개인정보처리방침
- `node check.js`: 형식을 검사하고, 이론 예시 코드·출력 문제·함정 표를 실제로 실행해 결과가 적힌 답과 같은지 확인 (DOM 예시는 `npm i jsdom` 필요)
- 모든 설명·문제·보기·해설·그림은 새로 작성했습니다.
- JavaScript는 Oracle의 상표이며, 이 앱은 Oracle 및 어떤 시험·교육 기관과도 관련 없는 개인 학습용 앱입니다.
